### About Application Screens & Features

Authentication Screens (Login & Sign Up)
   - Custom UI & Branding: Clean layout featuring custom app logo and themed green primary buttons.
   - Form Validation: Input handling for email, username, and password fields.
   - Interactive UI: Password visibility toggle (Show/Hide password) and seamless navigation links between screens.

Shop Screen
   - Location & Search: Top bar displaying user location header and an intuitive search bar.
   - Promo Banner Slider: Dynamic offer banners with page indicator dots.
   - Groceries Section Banners: Smooth horizontal scrolling category banners (e.g., Pulses & Rice) with custom styling.
   - Product Showcase: Custom reusable product cards displaying dynamic images, item details, individual pricing, and interactive "Add" buttons.
   - Horizontal Categorization: Product sections (Exclusive Offer, Best Selling, Groceries) with independent horizontal scrolling.

 Product Detail Screen
   - Header & Media: Large product image header with back navigation and favorite toggle buttons.
   - Item Specifications: Interactive quantity selector with dynamic price updates, detailed descriptions, and expandable info sections.
   - Action Button: Full-width "Add To Basket" button for item purchase flow.

Account Screen
   - Profile Overview: User profile header displaying avatar image, user name, email, and edit option.
   - Account Settings List: Structured navigation options including Orders, My Details, Delivery Address, Payment Methods, Promo Card, Notifications, Help, and About.
  Session Management: Styled "Log Out" action button with custom icon and layout.

Navigation & UI Shell
  Bottom Navigation Bar: Custom bottom navigation for smooth switching between main app sections (Shop, Explore, Cart, Favourite, Account)
